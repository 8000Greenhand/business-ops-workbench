# 药师帮指标字典草案

仅记录本轮真实文件中发现的指标候选；不进入正式指标层。

| 指标 | 真实字段/公式证据 | 状态 | 限制 |
|---|---|---|---|
| 本日 GMV | `数据明细!本日GMV`；由订单 `进货金额` 按 `日期` 的 `SUMIFS` 汇总 | `VERIFIED`（模板计算关系） | 仅验证了模板计算关系，不等于正式 GMV 业务口径 |
| 周 GMV/本周达成 | `数据看板` 通过日期汇总/`OFFSET` 计算 | `LIKELY` | 周边界、目标期间和缺失日处理需确认 |
| 月累计 GMV | `数据看板` 对 `数据明细` 按月份累计 | `LIKELY` | 不是商家级月快照；是否含退款/取消未确认 |
| 平台补贴金额 | `数据明细!补贴金额`、订单 `药师帮品种补贴` | `PARTIAL` | 两个字段的口径关系未确认 |
| 采购金额/进货金额 | `订单原始数据!进货金额` | `VERIFIED`（字段存在） | 订单状态、退款、取消和结算口径未确认 |
| 订单数 | `订单原始数据!订单ID` | `VERIFIED`（可计数） | 订单行拆分，需按订单 ID 去重；业务有效订单规则未确认 |
| 采购客户数 | `药店编码`/`药店全称` | `PARTIAL` | 需确认客户去重和有效订单条件 |
| 动销商品数 | `商品ID`/`商品编码` | `PARTIAL` | 需确认有效订单和商品去重键 |
| 活动商品数 | 活动原始数据的活动 ID、商品字段 | `PARTIAL` | 活动状态和有效期规则未确认 |
| 流量/访问/点击 | `流量分析` 的访问、点击、曝光字段 | `LIKELY` | 当前为汇总序列，不一定能按商家关联 |
| GMV目标/达成率 | `数据看板`、`11月目标`及公式 | `PARTIAL` | 目标表日期/期间与日报当前日期存在错位，不能直接进入 KPI |
| 新开商家 | 绩效目录和历史解压文件中的候选字段 | `PARTIAL` | 当前日报没有稳定商家 ID，无法验证实际值 |
| 有效品次/优质品次 | 绩效文件候选 | `BLOCKED` | 规则与实际明细的稳定关联未建立 |

只有“字段存在/模板公式关系”达到 `VERIFIED`，不代表已经达到正式业务口径 VERIFIED。
