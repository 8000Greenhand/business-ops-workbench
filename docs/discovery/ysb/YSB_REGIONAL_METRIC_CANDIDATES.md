# YSB Dashboard A 区域经营指标候选

## VERIFIED

这里的 VERIFIED 表示“源表中存在明确字段、明确时间×商家结构或明确目标/实际列”，不表示业务口径已经完成最终签字。

| 指标 | 来源 | 粒度 | 可用性 |
|---|---|---|---|
| 现金额/销售额候选 | 销售额统计（按月） | month × 供应商名称 | `VERIFIED`，最适合近期主看板 |
| 订单数 | 销售额统计（按月）/商业售后情况 | month × 商家 | `VERIFIED`，需确认是否有效订单 |
| 月 GMV 候选 | 商业每月GMV `aYYYYMM` 列 | merchant × month | `VERIFIED`（实际值字段存在），需明确空值/0和业务口径 |
| 商家原因售后订单数/率 | 商业售后情况 | month × merchant | `VERIFIED`（字段存在），适合异常辅助 |
| 运营人员/商务对接人 | 销售额统计、绩效表 | month × merchant/owner | `VERIFIED`（归属字段存在），历史变更需保留 |

## LIKELY

| 指标 | 来源 | 适合的分析 |
|---|---|---|
| 目标达成率 | 商家 actual + 总体目标/绩效目标候选 | 只有 target 与 actual 粒度确认后可计算 |
| 环比 | 月度销售额/GMV | 同一来源、同一口径、相邻月份 |
| 同比 | 商业每月GMV历史列 | 2023-01 至 2026-07 候选，但月份空值和版本需先处理 |
| 商家排名 | 月度现金额/GMV | 可做截面排名，需固定口径和覆盖范围 |
| 贡献度 | 商家月销售额/GMV占区域总额 | 可做，但必须保证商家覆盖完整 |
| 实时在架 SKU 数 | 新开商业情况 | 商家活跃/供给异常候选 |
| 动销店数、分店 GMV | 新开商业情况 | 新开商家和经营扩张识别候选 |
| 有效新开、有效计件 | 新开商业情况、总体目标 | KPI 候选，定义仍需确认 |

## PARTIAL

| 指标 | 原因 |
|---|---|
| GMV 目标完成率 | 目标主要见整体/人员层，商家 actual 虽有，但没有已验证的同粒度 target |
| 新开商家 KPI | 存在开店/首单/新开有效字段，但不同版本是子集或快照，去重和有效定义未统一 |
| 活跃 SKU / 动销商品 | 有实时在架 SKU、动销店数等字段，但跨文件口径和月份快照关系未确认 |
| 区域排名 | 有省份/城市字段，但内部区域与行政区映射未确认 |
| 经营健康分 | 可以由已确认指标组合，但当前没有业务批准的公式 |

## BLOCKED

- 商家正式 `merchant_id`
- 商家级 target_completion_rate
- 以商家为主体的同比/环比全历史连续序列（版本覆盖不完整）
- 直接从 RAR 汇总表推导订单级客单、采购客户数和商品贡献
- 在没有商家覆盖完整性证明时发布区域总额贡献度

## 异常商家识别可行性

V1 可以先做 staging 级异常筛选，规则仅使用事实存在的字段：

- 最近月现金额/GMV低于上一月：需要至少两个同口径月份
- 订单数下降且售后率上升：需要同一商家同一期间的两类字段
- GMV下降但在架 SKU/动销店数不降：作为候选异常，不直接解释原因
- 新开有效/有效计件缺失或异常：仅在绩效定义确认后启用
- 同月低于区域分位数：仅在商家覆盖完整的同一快照内启用

## Dashboard A 最小指标集合

第一版建议只做：

1. 月现金额/销售额候选
2. 月 GMV 候选
3. 订单数
4. 商家原因售后率/售后订单数
5. 上月环比
6. 商家排名
7. 运营人员/商务归属
8. 数据覆盖月数与商家覆盖数

目标达成率、新开商家、有效品次、贡献度先作为条件开启指标，待 target 粒度和覆盖完整性确认后再启用。
