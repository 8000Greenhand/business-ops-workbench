# 药师帮历史数据资产盘点

## 审计范围与状态

本轮审计了项目目录中的已解压数据目录：

`business-ops-workbench/绩效与商家销售额汇总/`

该目录没有对应的原始 `绩效与商家销售额汇总.rar` 文件，也没有找到精确命名的 `药师帮日报.xlsx`。因此以下结果代表“已存在的解压目录资产”，不是对缺失 RAR 容器的完整性证明。

审计方式：本地、只读、`openpyxl` 流式读取 XLSX；输出只保留结构和统计元数据，样例值已掩码，未修改原始文件。

## 数据类别候选

从文件名、Sheet 字段和结构共同观察到的候选类别：

- 商家/商业经营汇总与商家进度
- 商业每日 GMV、销售额统计及期间汇总
- 新开商业商家、商家历史/保证金等过程或经营表
- 药品/商品统计、商品排名或价格相关表
- 绩效方案、绩效结果、区域运营和客户成功相关表
- 售后、采购、开店/开分店等专项统计

这些是候选分类，不等同于已确认的正式事实表。

## 时间覆盖

有效日期候选主要覆盖 2024-12 至 2026-07；部分经营明细出现 2023-01 至 2026-07。若干字段中的异常历史/未来日期仍可能是 ID、编码或导出值误读，不能直接作为业务日期范围。日期候选详见 `YSB_DATA_INVENTORY.csv`。

## 粒度判断

- `商业每日GMV` 类 Sheet：LIKELY 日级商家快照/汇总，但需确认 GMV 的统计日与累计口径。
- `销售额统计` 的日/月/周期 Sheet：LIKELY 汇总或快照，不应直接当作订单流水。
- 绩效方案/结果表：LIKELY 目标或期间绩效汇总，时间粒度和评价周期需人工确认。
- 商品统计：LIKELY 商品或品种汇总，尚未证明是订单级明细。

## 重复与版本

同一结构的日期版本和带 `(1)`、`(2)` 等后缀文件明显存在。审计统计到 46,918 个重复行事件，但这是逐 Sheet 的完全重复行计数，不能直接解释为业务重复订单。不得删除或合并，详见 `YSB_DUPLICATE_VERSION_MAP.csv`。

## 最值得后续进入模型的资产

优先人工确认：商家经营综合汇总、商业每日 GMV、商家进度/新开商家、商品统计、绩效结果与目标表。只有在确认商家 ID、日期口径、快照/流量性质和 GMV 口径后，才能设计正式数据模型。
