# 超级经纪人运营系统｜模拟经营 Demo

本文件只定义当前 Demo 的可复现压力测试口径。页面使用完全虚构经纪人、经理、片区和固定 seed 日事实；城市名称仅作演示，不代表贝壳或任何平台的内部数据、标准、组织结构或运营流程。

## 决策链

日事实 → 28 天经营表现与 14 天趋势 → 56 天成交样本 → 每周生命周期快照 → 同群比较 → 潜力与置信度 → 持续/极端瓶颈 → 带守卫的 Top3 动作 → 经理容量分配 → 会话内任务状态 → 历史模拟动作观察。

配置分别保存在 `config/super_agent_ops.yaml` 和 `config/super_agent_actions.yaml`。所有阈值仅为模拟压力测试口径。`agent_master` 和 `agent_daily_metrics` 由 `simulation/super_agent.py` 生成；`strategy_rule_config` 与 `action_catalog` 来自 YAML；`agent_stage_snapshot`、`agent_action_recommendation`、`operation_action_log` 和 `campaign_exposure` 为内存 DataFrame，不使用数据库或外部服务。

## 口径与局限

- 周快照的阶段互斥。头部达标立即进入新晋，连续达标进入稳定；首次失守保留头部并打风险标签；连续失守后回落。高潜和准头部需确认周期，极端沉默可立即回落。
- 头部标准支持 AND/OR：AND 取必选项最小完成度，OR 取最优可达路径。Demo 中成交量与成交额阈值都是虚构配置。
- Potential Score 仅用于非头部潜力识别，不直接决定 Priority。趋势使用 `log1p` 差值再做同群百分位；转化项在分母不足时退出并重归一化。零分母返回 NULL，缺失为不可用。
- 同群优先为同城市和同候选阶段，样本不足依次扩大到同城市相邻阶段、全城市同阶段、全局可比较人群。结果保留同群范围和人数。由于 Demo 城市差异很小，百分位只说明模拟人群中的相对位置。
- Confidence 独立考虑观测完整度、观察长度、商机与带看样本、可计算漏斗比例、同群规模。低置信度优先补样本；即使潜力分高，也不能直接获取资源动作。
- 瓶颈要求持续或极端同群偏低。资源瓶颈还需后链路综合效率高；成交瓶颈优先 56 天样本。样本不足时不评价能力。Fact 是观察到的量和同群位置；Diagnostic 是基于模拟阈值的异常提示；Recommendation 是带资格和容量守卫的建议，不是因果结论。
- P0 门槛先于经理容量，容量是上限而非配额。触达频率和 cooldown 会降低排序或抑制动作。A07 只有活动开启且预算、容量可用时才有资格；页面不承诺真实奖金。
- A–H 是从固定 seed 的派生结果中按验收条件挑选的代表人物标签，不改写其指标或诊断。E 的原始事实显式模拟末 7 天与此前少量离散日期的稀疏观测；缺失天数不被填成零。
- 复盘页的推荐、接受和执行量来自模拟推荐与历史动作记录，7/14/28 天改善来自行动前后成交计数观察。周期和队列只是 Demo 示例，不具备真实归因能力；普通前后对比不能直接证明因果。活动实验组和对照组以固定 seed 随机分配，未构造可用于真实业务结论的效果。
- 工作台接受、执行和跳过保存在 `st.session_state`，只对本次会话有效。
