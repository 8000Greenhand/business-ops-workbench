# 超级经纪人运营系统｜2–3 分钟演示路径

| 页面 | 讲什么 | 核心一句话 | 建议点击 |
| --- | --- | --- | --- |
| 经营总览 | 头部规模、净新增、准头部晋级与头部留存 | 先看增长与保卫是否同时发生。 | 看“本周经营摘要”。 |
| 成长漏斗 | 各阶段人数、进入流出、晋级回落 | 找出成长卡住的阶段，而非只看成交榜。 | 看阶段迁移表。 |
| 经营决策中心 | P0 准头部为何优先、同群证据、主瓶颈与 Top3 NBA | 生命周期、潜力、优先级和动作是四个独立判断。 | 筛选 P0 和准头部，再看案例B/C/F/E。 |
| 城市经理工作台 | 本周 P0 任务与接受、执行、跳过 | 策略中台把重点对象和建议动作交给城市经理协同执行。 | 选有 P0 的经理，接受一项任务，再执行。 |
| 策略实验与复盘 | 会话进度、历史同 cohort 漏斗、观察与实验 | 最终要检验投入价值；普通前后对比不能证明因果。 | 看“本次会话执行进度”和“历史模拟策略效果”。 |

全程说明：城市、人物、阈值和结果均为模拟经营 Demo，非贝壳内部口径。
