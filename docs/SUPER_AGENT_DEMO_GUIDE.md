# 超级经纪人运营系统 V2｜2–3 分钟演示路径

| 页面 | 讲什么 | 核心一句话 | 建议点击 |
| --- | --- | --- | --- |
| 经营总览 | 头部规模、净新增、准头部晋级与头部留存 | 先看增长与保卫是否同时发生。 | 看“本周经营摘要”。 |
| 成长漏斗 | 各阶段人数、进入流出、晋级回落 | 找出成长卡住的阶段，而非只看成交榜。 | 看阶段迁移表。 |
| 经营决策中心 | P0 准头部为何优先、同群证据、主瓶颈与 Top3 NBA | 经纪人可匹配多场活动；Fit 和百分位只在各自活动内解释。 | 筛选 P0 和准头部，再看案例B/C/F/E及“当前可承接活动”。 |
| 活动策略中心 | 中台统一定义 C02 规则、预算、名额；系统生成候选 | 当前有效活动含报名中与进行中；跨活动候选、报名按人次统计。 | 看顶部状态，再选 C02 查看候选和负责人。 |
| 城市经理工作台 | 同一经理既看 P0 任务，也决定活动报名 | 城市经理可以报名或记录不参加原因。 | 打开“我的活动”，选 C02，为一人报名、另一人选择不参加原因。 |
| 策略与活动复盘 | 会话报名进度与历史成交、晋级、成本分开 | 执行过程到“完成”为止；成交和晋级是并列观察结果，均不能单凭前后对比证明增量。 | 对照本次会话报名数、C02 两组结果和执行过程。 |

全程说明：城市、人物、活动、预算、名额、奖励、阈值和结果均为固定 Seed 模拟经营 Demo，非任何平台内部口径。V2 仅在本地分支验收，公网仍为 V1。
